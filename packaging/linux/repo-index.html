AudioStrada packages

Linux repositories

The APT and RPM repositories of AudioStrada, a digital audio workstation for Linux, Windows and macOS.

The .deb and .rpm packages from audiostrada.com/download add these repositories by themselves: new versions then come with your system's updates. To add them by hand instead:

Debian, Ubuntu

Ubuntu 24.04, Debian 13 or later (amd64).

url=https://packages.audiostrada.com
sudo mkdir -p /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/audiostrada-packages.asc $url/audiostrada-packages.asc
sudo curl -fsSLo /etc/apt/sources.list.d/audiostrada.sources $url/audiostrada.sources
sudo apt update
sudo apt install audiostrada

Fedora

Fedora 40 or later (x86_64).

url=https://packages.audiostrada.com
sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-audiostrada $url/audiostrada-packages.asc
sudo curl -fsSLo /etc/yum.repos.d/audiostrada.repo $url/audiostrada.repo
sudo dnf install audiostrada
