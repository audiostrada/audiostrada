# Glossaire

| Terme | Sens |
|---|---|
| **Aimant** | les positions attirées par la grille, les bords des clips, les marqueurs, la tête de lecture ou les transitoires |
| **Automation** | le mouvement d'une commande dans le temps, dessiné sur une piste d'automation |
| **Bounce** | rendre une piste, avec ses effets, sur une nouvelle piste |
| **Buffer** | la quantité d'audio traitée d'un coup : plus petit, moins de latence ; plus grand, moins de décrochages |
| **Bus** | une tranche qui additionne les pistes routées vers elle (et des sends), pour les traiter ensemble ; elle ne porte pas de clips |
| **Clip** | un morceau d'audio ou de MIDI sur une piste |
| **Comping** | construire une prise avec les meilleurs passages de plusieurs |
| **Consolider** | rendre plusieurs clips en un seul fichier |
| **Crête réelle** | le plus haut niveau du signal entre les échantillons, une fois converti en analogique |
| **dBFS** | décibels sous le maximum numérique : 0 dBFS est le plus fort possible pour un échantillon |
| **Départ** | une copie du signal d'une piste envoyée vers une autre, avant ou après son fader |
| **Dither** | un bruit très faible qui garde propres les passages calmes en passant à 16 bits |
| **Fondu enchaîné** | un fondu de sortie et un fondu d'entrée sur le chevauchement de deux clips |
| **Geler** | rendre une piste pour économiser du calcul, de façon réversible |
| **Insert** | un effet placé sur le trajet d'une piste |
| **Latence** | le délai entre un son qui entre et qui sort |
| **LUFS** | unités de sonie, comme la mesurent les plateformes de streaming (-14 LUFS pour la plupart) |
| **MCP** | le Model Context Protocol, par lequel les assistants IA pilotent AudioStrada |
| **MIDI** | des notes et des commandes, pas du son : un instrument les transforme en son |
| **MPE** | du MIDI où chaque note a son canal, pour la hauteur, la pression et le timbre de chaque note |
| **Plage** | une portion de temps sur une ou plusieurs pistes |
| **Playlist** | une autre version des clips d'une piste, comme chaque prise d'un enregistrement en boucle |
| **Punch** | enregistrer seulement entre deux points |
| **Réglage des gains** | régler le niveau de chaque étage pour que les effets et les consoles travaillent là où ils sonnent le mieux |
| **Sidechain** | un effet commandé par le signal d'une autre piste (un compresseur qui baisse la basse sous la grosse caisse) |
| **Stem** | l'export d'une piste ou d'un groupe seul |
| **Transitoire** | l'attaque d'un son, comme un coup de batterie |
| **VCA** | un fader qui bouge les niveaux de plusieurs pistes ensemble, en gardant leur équilibre |
