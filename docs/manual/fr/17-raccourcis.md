# Raccourcis clavier

Voici les raccourcis par défaut du jeu **AudioStrada**. Préférences › Clavier change n'importe
lequel, ou choisit le jeu Pro Tools, Logic ou Reaper. Sous macOS, [[Cmd]] remplace [[Ctrl]].

## Transport

| Touches | Commande |
|---|---|
| [[Space]] | lecture / arrêt (retour là où la lecture a commencé) |
| [[R]] | enregistrer |
| [[Home]] / [[End]] | aller au début / à la fin |
| [[L]] | boucle |
| [[Shift+L]] | boucler les clips sélectionnés |
| [[P]] | punch |
| [[K]] / [[Shift+K]] | métronome / réglages du métronome |
| [[Alt+R]] | écouter la référence / le mix |
| [[Tab]] / [[Shift+Tab]] | transitoire suivant / précédent |
| [[M]], [[.]], [[,]] | ajouter un marqueur, marqueur suivant, précédent |

## Édition

| Touches | Commande |
|---|---|
| [[1]] … [[5]] | outil intelligent, plage, ciseaux, gomme, muet |
| [[Ctrl+Z]] / [[Ctrl+Shift+Z]] ou [[Ctrl+Y]] | annuler / rétablir |
| [[Ctrl+C]] / [[Ctrl+X]] / [[Ctrl+V]] | copier / couper / coller à la tête de lecture |
| [[S]] | scinder à la tête de lecture |
| [[Ctrl+D]] | dupliquer |
| [[Delete]] | supprimer |
| [[Ctrl+A]] / [[Escape]] | sélectionner tous les clips / désélectionner |
| [[Left]] / [[Right]] | décaler |
| [[F1]] / [[F2]] / [[F4]] | mode Shuffle / Slip / Grille |
| [[G]] | aimant |
| [[Ctrl+Shift+=]] / [[Ctrl+Shift+-]] | grille plus fine / plus large |
| [[Ctrl+F]] | fondus sur la plage, ou courts fondus sur les clips sélectionnés |
| [[Shift+R]] | plage sur les clips sélectionnés |
| [[Ctrl+Shift+R]] | rogner le projet à la sélection |
| [[Ctrl+Shift+Delete]] / [[Shift+Delete]] | supprimer / vider le passage |
| [[Ctrl+U]] / [[Ctrl+H]] / [[Ctrl+Shift+C]] | supprimer les silences / recoller / consolider |
| [[Alt+P]] / [[Alt+B]] / [[Alt+G]] | traiter les clips / Beat Detective / Groove |
| [[Q]] | quantifier les notes |

## Pistes

| Touches | Commande |
|---|---|
| [[Ctrl+Shift+T]] / [[Ctrl+Shift+N]] | ajouter une piste audio / plusieurs |
| [[Ctrl+Alt+T]] | ajouter une piste stéréo |
| [[Ctrl+Shift+I]] | ajouter une piste instrument |
| [[Ctrl+Shift+M]] | nouveau clip MIDI |
| [[Ctrl+Shift+D]] / [[Ctrl+Delete]] | dupliquer / supprimer les pistes sélectionnées |
| [[Ctrl+Up]] / [[Ctrl+Down]] | sélectionner la piste précédente / suivante |
| [[Alt+Up]] / [[Alt+Down]] | monter / descendre la piste |
| [[Shift+Alt+M]] / [[Shift+Alt+S]] / [[Shift+Alt+R]] | muet / solo / armement des pistes sélectionnées |
| [[Ctrl+G]] / [[Ctrl+Shift+G]] | grouper les pistes sélectionnées / suspendre les groupes |

## Affichage

| Touches | Commande |
|---|---|
| [[+]] / [[-]] / [[F]] | zoom avant / arrière / toute la session |
| [[Z]] | zoom sur la sélection (à nouveau : retour) |
| [[Ctrl+Shift+Up]] / [[Ctrl+Shift+Down]] | pistes plus hautes / moins hautes |
| [[Alt+Shift+Up]] / [[Alt+Shift+Down]] / [[Alt+Shift+0]] | zoom de forme d'onde avant / arrière / remise à zéro |
| [[Alt+0]] … [[Alt+6]] | timeline, Mixer, piano roll, navigateur, inspecteur, marqueurs, rack |
| [[Ctrl+M]] / [[Ctrl+P]] | Mixer / piano roll dans sa propre fenêtre |
| [[Shift+Alt+C]] | Mixer compact |
| [[F11]] | plein écran |

## Fichiers et fenêtres

| Touches | Commande |
|---|---|
| [[Ctrl+N]] / [[Ctrl+O]] | nouveau projet / ouvrir |
| [[Ctrl+S]] / [[Ctrl+Shift+S]] | enregistrer / enregistrer sous |
| [[Ctrl+I]] / [[Ctrl+Alt+I]] | importer de l'audio / un fichier MIDI |
| [[Ctrl+Shift+E]] | exporter |
| [[Ctrl+Alt+N]] / [[Ctrl+Alt+O]] | nouvel onglet de projet / ouvrir dans un nouvel onglet |
| [[Ctrl+Tab]] / [[Ctrl+Shift+Tab]] / [[Ctrl+W]] | onglet suivant / précédent / fermer l'onglet |
| [[Ctrl+Shift+P]] | palette de commandes |
| [[Ctrl+,]] | préférences |
| [[Ctrl+/]] | la liste des raccourcis |
| [[Ctrl+Q]] | quitter |

## Souris

| Geste | Effet |
|---|---|
| [[Ctrl]]+molette | zoom dans le temps, autour du pointeur |
| [[Alt]]+molette | hauteur des pistes |
| [[Alt+Shift]]+molette | zoom de forme d'onde |
| [[Shift]]-glisser | sélectionner une plage |
| [[Alt]]-glisser un clip | le copier |
| [[Ctrl]]-glisser un clip | volume du clip |
| [[Ctrl+Alt]]-glisser un clip | glisser son contenu |
| [[Alt]]-glisser le bord droit d'un clip | étirer dans le temps |
| Double-clic sur un fader ou un bouton | retour à sa valeur par défaut |
| [[Shift]]-glisser un fader ou un bouton | pas fins |
