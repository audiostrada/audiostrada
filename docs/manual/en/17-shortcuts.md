# Keyboard shortcuts

These are the defaults of the **AudioStrada** preset. Preferences › Keyboard changes any of
them, or picks the Pro Tools, Logic or Reaper preset. On macOS, [[Cmd]] replaces [[Ctrl]].

## Transport

| Keys | Command |
|---|---|
| [[Space]] | play / stop (back to where playback started) |
| [[R]] | record |
| [[Home]] / [[End]] | go to start / end |
| [[L]] | loop on or off |
| [[Shift+L]] | loop the selected clips |
| [[P]] | punch on or off |
| [[K]] / [[Shift+K]] | metronome / metronome settings |
| [[Alt+R]] | listen to the reference / the mix |
| [[Tab]] / [[Shift+Tab]] | next / previous transient |
| [[M]], [[.]], [[,]] | add a marker, next marker, previous marker |

## Editing

| Keys | Command |
|---|---|
| [[1]] … [[5]] | Smart, Range, Scissors, Eraser, Mute tool |
| [[Ctrl+Z]] / [[Ctrl+Shift+Z]] or [[Ctrl+Y]] | undo / redo |
| [[Ctrl+C]] / [[Ctrl+X]] / [[Ctrl+V]] | copy / cut / paste at the playhead |
| [[S]] | split at the playhead |
| [[Ctrl+D]] | duplicate |
| [[Delete]] | delete |
| [[Ctrl+A]] / [[Escape]] | select all clips / deselect |
| [[Left]] / [[Right]] | nudge |
| [[F1]] / [[F2]] / [[F4]] | Shuffle / Slip / Grid mode |
| [[G]] | snap on or off |
| [[Ctrl+Shift+=]] / [[Ctrl+Shift+-]] | finer / coarser grid |
| [[Ctrl+F]] | fades on the range, or short fades on the selected clips |
| [[Shift+R]] | range over the selected clips |
| [[Ctrl+Shift+R]] | crop the project to the selection |
| [[Ctrl+Shift+Delete]] / [[Shift+Delete]] | remove / clear the section |
| [[Ctrl+U]] / [[Ctrl+H]] / [[Ctrl+Shift+C]] | strip silence / heal / consolidate |
| [[Alt+P]] / [[Alt+B]] / [[Alt+G]] | process clips / Beat Detective / Groove |
| [[Q]] | quantize notes |

## Tracks

| Keys | Command |
|---|---|
| [[Ctrl+Shift+T]] / [[Ctrl+Shift+N]] | add an audio track / several |
| [[Ctrl+Alt+T]] | add a stereo track |
| [[Ctrl+Shift+I]] | add an instrument track |
| [[Ctrl+Shift+M]] | new MIDI clip |
| [[Ctrl+Shift+D]] / [[Ctrl+Delete]] | duplicate / delete the selected tracks |
| [[Ctrl+Up]] / [[Ctrl+Down]] | select the previous / next track |
| [[Alt+Up]] / [[Alt+Down]] | move the track up / down |
| [[Shift+Alt+M]] / [[Shift+Alt+S]] / [[Shift+Alt+R]] | mute / solo / arm the selected tracks |
| [[Ctrl+G]] / [[Ctrl+Shift+G]] | group the selected tracks / groups on or off |

## View

| Keys | Command |
|---|---|
| [[+]] / [[-]] / [[F]] | zoom in / out / fit the session |
| [[Z]] | zoom to the selection (again: back) |
| [[Ctrl+Shift+Up]] / [[Ctrl+Shift+Down]] | taller / shorter tracks |
| [[Alt+Shift+Up]] / [[Alt+Shift+Down]] / [[Alt+Shift+0]] | waveform zoom in / out / reset |
| [[Alt+0]] … [[Alt+6]] | timeline, mixer, piano roll, browser, inspector, markers, rack |
| [[Ctrl+M]] / [[Ctrl+P]] | mixer / piano roll in its own window |
| [[Shift+Alt+C]] | compact mixer |
| [[F11]] | full screen |

## Files and windows

|---|---|
| [[Ctrl+N]] / [[Ctrl+O]] | new / open project |
| [[Ctrl+S]] / [[Ctrl+Shift+S]] | save / save as |
| [[Ctrl+I]] / [[Ctrl+Alt+I]] | import audio / import a MIDI file |
| [[Ctrl+Shift+E]] | export |
| [[Ctrl+Alt+N]] / [[Ctrl+Alt+O]] | new project tab / open in a new tab |
| [[Ctrl+Tab]] / [[Ctrl+Shift+Tab]] / [[Ctrl+W]] | next tab / previous tab / close the tab |
| [[Ctrl+Shift+P]] | command palette |
| [[Ctrl+,]] | preferences |
| [[Ctrl+/]] | the list of shortcuts |
| [[Ctrl+Q]] | quit |

## Mouse

| Gesture | Effect |
|---|---|
| [[Ctrl]]+wheel | zoom time, around the pointer |
| [[Alt]]+wheel | track height |
| [[Alt+Shift]]+wheel | waveform zoom |
| [[Shift]]-drag | select a range |
| [[Alt]]-drag a clip | copy it |
| [[Ctrl]]-drag a clip | clip volume |
| [[Ctrl+Alt]]-drag a clip | slip its content |
| [[Alt]]-drag a clip's right edge | time stretch |
| Double-click a fader or a knob | back to its default |
| [[Shift]]-drag a fader or a knob | fine steps |
