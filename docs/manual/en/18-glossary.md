# Glossary

| Term | Meaning |
|---|---|
| **Automation** | the movement of a control over time, drawn in a lane |
| **Bounce** | rendering a track, with its effects, onto a new track |
| **Buffer size** | how much audio is processed at once: smaller gives less latency, larger fewer dropouts |
| **Bus** | a track that receives other tracks, through sends or as a folder, to process them together |
| **Clip** | a piece of audio or MIDI on a track |
| **Comping** | building one take from the best parts of several |
| **Consolidate** | rendering several clips into a single file |
| **Crossfade** | a fade-out and a fade-in over the overlap of two clips |
| **dBFS** | decibels below digital full scale: 0 dBFS is the loudest a sample can be |
| **Dither** | a faint noise that keeps quiet passages clean when going down to 16 bits |
| **Freeze** | rendering a track to save processing power, reversibly |
| **Gain staging** | setting each stage's level so that effects and consoles work where they sound best |
| **Insert** | an effect placed on a track's path |
| **Latency** | the delay between a sound going in and coming out |
| **LUFS** | loudness units, as streaming services measure loudness (-14 LUFS for most) |
| **MCP** | the Model Context Protocol, through which AI assistants drive AudioStrada |
| **MIDI** | notes and controls, not sound: an instrument turns them into sound |
| **MPE** | MIDI where each note has its own channel, for pitch, pressure and timbre per note |
| **Playlist** | another version of a track's clips, such as each take of a loop recording |
| **Punch** | recording only between two points |
| **Range** | a stretch of time on one or several tracks |
| **Send** | a copy of a track's signal sent to another track, before or after its fader |
| **Sidechain** | an effect driven by another track's signal (a compressor ducking the bass under the kick) |
| **Snap** | positions pulled to the grid, clip edges, markers, the playhead or transients |
| **Stem** | the export of one track or group alone |
| **Transient** | the attack of a sound, such as a drum hit |
| **True peak** | the highest level of the signal between samples, once converted to analogue |
| **VCA** | a fader that moves the levels of several tracks together, keeping their balance |
