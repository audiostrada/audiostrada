# Building AudioStrada

On every system:

- The Rust version is pinned in `rust-toolchain.toml`; `rustup` installs it on the first `cargo`
  command.
- A build from source has no limit at all: the evaluation mode only exists in the official
  builds (the `official` feature, see [distribution.md](distribution.md)).
- LV2 is optional everywhere: `lilv` is loaded at startup, not linked at build time.

## Linux

### Requirements

1. **rustup** (https://rustup.rs).
2. A C toolchain and the audio development files. PipeWire's bindings are generated by bindgen,
   hence `libclang`.

| Distribution | Command |
|---|---|
| Debian, Ubuntu | `sudo apt install build-essential libpipewire-0.3-dev libspa-0.2-dev libclang-dev libasound2-dev libjack-jackd2-dev` |
| Fedora | `sudo dnf install gcc pipewire-devel alsa-lib-devel pipewire-jack-audio-connection-kit-devel clang-devel` |
| Arch | `sudo pacman -S base-devel pipewire alsa-lib pipewire-jack clang` |

The CI builds on Ubuntu 24.04; the Fedora and Arch package names are given for convenience.

### Build and run

```sh
git clone https://github.com/audiostrada/audiostrada.git
cd audiostrada
cargo run --release -p audiostrada-app
```

The binary is `target/release/audiostrada`. Run `audiostrada diagnose` once: it checks real-time
priority, PipeWire buffers, the CPU governor and kernel preemption, and tells how to fix them.

MP3 export runs the `audiostrada-mp3` helper, looked for next to the binary and then on the
`PATH`: build it with `cargo build --release -p audiostrada-mp3`. This holds on every platform.

### Packages

| Package | Command | Tool |
|---|---|---|
| `.deb` | `cargo deb -p audiostrada-app` | `cargo install cargo-deb` |
| `.rpm` | `cargo generate-rpm -p crates/audiostrada-app --profile dist` | `cargo install cargo-generate-rpm` |
| `.AppImage` | `sh packaging/linux/build-appimage.sh` | [appimagetool](https://github.com/AppImage/appimagetool/releases) on the `PATH` |

The `.deb` and `.rpm` also package the MP3 helper: build it first with
`cargo build -p audiostrada-mp3 --profile dist`.

Packages link the system's PipeWire, ALSA and JACK, whose daemons must match; they are not
bundled, not even in the AppImage.

### LV2 (optional)

Install `liblilv-0-0` (Debian, Ubuntu), `lilv` (Fedora, Arch).

## Windows (x64)

### Requirements

1. **Visual Studio Build Tools 2022** with the "Desktop development with C++" workload (MSVC and
   the Windows SDK). The SDK provides `rc.exe`, which embeds the icon in the executable; without
   it the build succeeds with a warning.
2. **rustup** (https://rustup.rs) with the default `x86_64-pc-windows-msvc` toolchain.
3. **Git**.

No audio SDK is needed: ASIO goes through COM with the installed drivers.

### Build and run

```powershell
git clone https://github.com/audiostrada/audiostrada.git
cd audiostrada
cargo run --release -p audiostrada-app
```

The binary is `target\release\audiostrada.exe`.

### Installer (`AudioStrada-<version>-x64-setup.exe`)

1. Install **Inno Setup 6** (https://jrsoftware.org/isinfo.php, or `choco install innosetup`).
2. Run:

```powershell
cargo build -p audiostrada-app --profile dist --locked
cargo build -p audiostrada-mp3 --profile dist --locked
$version = (Select-String -Path Cargo.toml -Pattern '^version = "(.*)"').Matches[0].Groups[1].Value
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" "/DVersion=$version" packaging\windows\audiostrada.iss
```

The installer is written to `target\installer\`. Unsigned, it triggers a SmartScreen warning on
its first run.

### LV2 (optional)

Put `lilv-0.dll` on the `PATH` or next to `audiostrada.exe`.

## macOS (Apple Silicon or Intel)

### Requirements

1. **Xcode**, or at least the Command Line Tools (`xcode-select --install`), which provide `cc`,
   `lipo` and `codesign`.
2. **rustup**:

```sh
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

CoreAudio comes with the system.

### Build and run

```sh
git clone https://github.com/audiostrada/audiostrada.git
cd audiostrada
cargo run --release -p audiostrada-app
```

Started from the Terminal, it is the Terminal that asks for microphone access, not AudioStrada.

### Universal app and `.dmg`

```sh
sh packaging/macos/bundle.sh
```

The script adds the `aarch64-apple-darwin` and `x86_64-apple-darwin` targets, builds both with the
`dist` profile, merges them with `lipo`, then writes `target/macos/AudioStrada.app` and
`target/macos/AudioStrada-<version>.dmg`.

### Signing (optional)

Set these variables before running the script:

```sh
export AUDIOSTRADA_SIGN_IDENTITY="Developer ID Application: Name (TEAMID)"
export AUDIOSTRADA_NOTARY_PROFILE=audiostrada        # created with xcrun notarytool store-credentials
export AUDIOSTRADA_BUNDLE_ID=com.audiostrada.AudioStrada  # optional
```

Unsigned, the app is blocked by Gatekeeper on its first launch: right-click it and choose Open,
or run:

```sh
xattr -dr com.apple.quarantine target/macos/AudioStrada.app
```

### LV2 (optional)

`brew install lilv`. On Apple Silicon, Homebrew installs to `/opt/homebrew/lib`, a folder the
loader does not search by default. When starting from the Terminal:

```sh
DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib ./target/release/audiostrada
```
